# NovelAI / ppnai 区域坐标约定

下游 `astrbot_plugin_ppnai` 的 `_pos_to_center`（`data_source.py`）把 CHARACTER 的 `position` 编成 `center {x,y}`：

| 轴 | 符号 | 方向 | 公式 |
| --- | --- | --- | --- |
| 水平 | 字母 **A–E** | **左 → 右** | `x = (ord(L)-ord('A')) * 0.2 + 0.1` |
| 垂直 | 数字 **1–5** | **上 → 下** | `y = (digit - 1) * 0.2 + 0.1` |

因此：

- `A1` = 左上，`E1` = 右上，`C3` = 正中，`A5` = 左下，`E5` = 右下。
- **竖条五格（全宽横条自上而下）** 应落在 **同一列、改行号**：`C1 C2 C3 C4 C5`（两人同格则 `B2+D2`）。
- **禁止**把字母当「第几格/第几行」：`A3 B3 C3 D3 E3` 会被编成一条水平线，centers 横摊。

插件主路径：**不让视觉模型直接赌 A1–E5**。模型输出 LAYOUT（归一化 bbox / `cx,cy`，原点左上），由 `manga_layout.center_to_pos` 按上表互逆公式计算格子。

无 LAYOUT 且 position 统计呈高置信轴对调时，才做一次字母↔数字转置兜底；这不是主方案。


## LAYOUT slots 对齐
slots 建议带 `who`/`tag`（如 `theresa (arknights)`），与 CHARACTER 身份一致，避免列表顺序错位导致错格。
